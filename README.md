# Multi-Buscador de Magnets 🧲

Este é um buscador de links multilingue desenvolvido para facilitar a coleta, mineração e organização de links torrent e protocolos Ace Stream para alimentação de bancos de dados JSON em projetos de streaming.

## 🚀 Funcionalidades Principais

- **Busca Multi-Fonte:** Acesso centralizado aos maiores indexadores:
  - **The Pirate Bay** & **1337x** (Geral)
  - **YTS** (Filmes otimizados)
  - **EZTV** (Séries de TV)
- **Suporte Ace Stream:** Busca dedicada para protocolos de transmissão ao vivo `acestream://`.
- **Área de Captura Integrada:** Campo de rascunho inteligente para colar e organizar links enquanto navega.
- **Exportação de Dados:** Função para baixar sua lista de capturas diretamente em um arquivo `.txt`.
- **Design Responsivo:** Interface otimizada para dispositivos Android (Dark Mode), ideal para uso no WebViewer do Kodular.

## 📱 Fluxo de Trabalho no APK

1. **Pesquisa:** Digite o título no campo de busca superior.
2. **Navegação:** Escolha a fonte. O site abrirá dentro da interface do seu aplicativo.
3. **Extração:** Ao localizar o link magnet, mantenha pressionado e selecione **"Copiar endereço do link"**.
4. **Armazenamento:** Retorne à tela inicial e cole o link na "Área de Captura".
5. **Finalização:** Clique em **"SALVAR LISTA"** para exportar seu progresso e alimentar seu arquivo JSON.

## 🛠️ Tecnologias

- **Frontend:** HTML5 e CSS3 (Layout Grid moderno).
- **Lógica:** JavaScript (Manipulação de URLs e geração de arquivos de texto).
- **Integração:** Compatível com componentes WebViewer em plataformas como Kodular.
